### 表格使用说明

1. 巡天 AX3000 的“名称—型号”关系是中兴路由器中最容易混淆的一组：零售宣传名叫“巡天 AX3000”，固件/认证型号是 **E2631**；而运营商定制版 **E2633 / E1630 / E2638** 分别对应移动、电信、联通渠道，无线核心规格与零售巡天 AX3000 基本一致，但内存容量、固件锁网策略和可刷机性因运营商和批次而异。

2. 问天 BE7200 Pro+ 的硬件型号存在 **SR7410** 与 **SR7420** 两种认证型号并存的情况，选购或刷机时建议以机身标签或固件内实际型号为准。

3. 运营商定制机的无线规格通常可以直接参考其对应的零售机型，但定制版可能存在**内存减配**（如部分 E1630 为 128MB）、**固件功能限制**或**运营商 APP 绑定**，硬件射频部分一般与零售版同源。

4. 表中“未明确统一硬件型号”的型号（如巡天 BE5100、晴天 BE5100、星云 BE3600 套装），目前公开资料多以宣传名作为产品标识，若需要精确的固件硬件版本号，建议以设备背面标签或登录后台查看“设备信息”为准。
